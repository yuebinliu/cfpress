# Plugins

Two free plugins. Pick the editor you already write in.

| | Download | Guide |
|---|---|---|
| **CF Press Sync** — WordPress | [↓ 2.2.1 · 130 KB](/releases/plugin/latest.zip) | [Install](/plugin/wordpress-plugin.html) |
| **CF Press Publisher** — Obsidian | [↓ 1.3.0 · 4.7 KB](/releases/obsidian/latest.zip) | [Install](/plugin/obsidian-plugin.html) |

**CF Press Sync** makes an existing WordPress site the editing backend: posts, media, categories and comments sync to Cloudflare, pages are served from the edge. WordPress 5.5+, PHP 7.0+.

**CF Press Publisher** publishes the note in front of you from Obsidian — Markdown as written, images uploaded, one command. Obsidian 1.0+.

All versions, including pinned builds: [Releases](/plugin/releases.html).
