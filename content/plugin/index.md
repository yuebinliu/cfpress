# The WordPress plugin

CF Press does not need WordPress. The plugin exists for one situation: you already run a WordPress site and want it served from Cloudflare without giving up the editor you know.

It is a companion, not a dependency.

## Start here

- **[What the plugin does](/plugin/overview.html)** — what moves in each direction, and when to skip it
- **[Installing the plugin](/plugin/install.html)** — auth key, upload, first export
- **[Sync rules](/plugin/sync-rules.html)** — who owns drafts, pull modes, comments

## The short version

| Direction | What moves | Started from |
|---|---|---|
| WordPress → CF Press | posts, media, categories, tags | Export in the plugin |
| CF Press → WordPress | posts written in the CMS | Pull from Worker |
| Comments | both ways | automatic, plus a manual sync |
