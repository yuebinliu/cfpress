# 多站点（站点 × 模型）设计草案 v1

> 状态：**设计草案，未实施**。目的：解决"所有站点共用一个生成目录"，并自然得到"多站点多模型"。
> 核心一句话：**一个「托管目标」= 一个站点 = 一个出口 = 一个独占的生成目录**。
> 相关：`hosting-templates.md`（模板/能力）、`hosting-config-context.md`（配置归属）。

## 1. 概念与不变量

- **站点就是「托管目标」**——不新增任何维度、不引入 site 表、不动 D1 表结构。
- 不变量：**一个生成目录只能属于一个站点** ⟺ **一个站点地址只能由一个模型服务**（同一条，两面）。
- 关系：**文章 ↔ 站点 = 多对多**（一篇可属于多个站点；一个站点有多篇文章）。
- 远端只有一份数据（自托管时由 Worker/D1 承载），靠 `wp_id` 维持 WP 端 ↔ Worker 端双向对齐 —— **本方案不改变这一点**。

## 2. 数据结构增补

托管目标（`cf_hosting_targets`）**新增/调整**字段：

| 字段 | 说明 |
|---|---|
| `id` | **数字自增**（系统分配、唯一、**不可变**）。**文章 meta 存它** ⇒ 它一变，文章就对不上站点 |
| `name` | 显示名（可中文，仅用于展示）|
| `dir` | **目录名**：可填（**仅英文/数字**），留空默认 = `id`；**必须位于 `CFSE_LOCAL_DIR/` 之下**；**保存后锁定、不可更改**（改名要重命名文件夹，不值当）。实际产物路径 = `<CFSE_LOCAL_DIR>/<dir>/<storagePath>` |
| `is_default` | 可选标记"默认站点"（**最多一个**）。未标记文章走它；**未设置 ⇒ 未标记文章不生成、不发布**（留在本地 WP）。默认站点**允许停用**，停用即等于未设置 |

其余字段不变：`template` / `transport` / `endpoint` / `auth_key` / `path_prefix` / `public_url` / `capabilities`。

文章 meta：

| 项 | 值 |
|---|---|
| 键 | `cfse_site`（**可见字段**，与 `content_format` 同惯例，便于后台手动改）|
| 值 | 站点 `id` 的**列表**（WP post meta 天然支持多行 ⇒ 一篇多站点）|

## 3. 目录与 URL 规则

| 形态 | 规则 |
|---|---|
| 本地产物 | `cfse-static/<dir>/<storagePath>`（`dir` 默认等于站点 `id`），`storagePath` 形如 `<slug>/index.html` |
| 远端对象 | 各目标自己的 `path_prefix` / bucket / 仓库**不变**；单页 key 仍是 `<slug>/index.html` |
| 为什么 key 相同没问题 | 同一篇文章发到多处，**key 本来就该相同**；不同站点各自是独立出口（独立 bucket/仓库/前缀）|

**统一加一级**：所有站点一律 `cfse-static/<id>/…`，无特例（包括默认站点），逻辑统一。

## 4. 行为

### 生成到本地
遍历**所有启用站点**，各自写自己的目录。**同一篇文章属于 N 个站点 ⇒ 渲染 1 次 HTML、写 N 处**（绝不渲染 N 次）。
目录不存在时**自动创建**（本地文件系统天然如此，无需任何配置；站点目录始终落在 `cfse-static/` 之下）。

### 发布整站
选择站点（或全部）⇒ 以**该站点的目录**作为源，推送到该站点的目标。
⇒ 「发布整站」卡里的**产物目录输入框退休**（从站点配置读，不再手填）。

### WP 侧保存/发布文章（自动导出）
按文章 meta 决定的站点集合分发；未标记 ⇒ 用默认站点；无默认站点 ⇒ **跳过**（内容只留本地 WP）。

## 5. 校验（很少，因为不变量靠推导而非检查）

| 项 | 处理 |
|---|---|
| `id` | 数字自增，用户不可填 ⇒ 唯一性天然满足 |
| **目录独占** | `dir` 可填 ⇒ **必须查重**：两个站点不能使用同一 `dir`（否则两站产物混在一起、地址对不上）。这是"一个站点地址不能由多个模型服务"的同一不变量 |
| 目录名合法性 | 仅 `[0-9a-zA-Z_-]`；必须位于 `CFSE_LOCAL_DIR/` 之下（不允许 `../` 或绝对路径）|
| 目录不可变 | 保存后锁定（不提供改名，避免重命名文件夹）|
| `id` 不可变 | 一旦被文章 meta 引用就不能改（改名只改 `name`）|
| 默认站点 | 最多一个；停用/删除 ⇒ 未标记文章转为"跳过"（**不算错误**）|

## 6. 涉及改动点（实施时逐个落）

| 位置 | 改动 |
|---|---|
| `get_post_storage_path()` | 产出"站点内相对路径"（不含站点段）|
| `build_post_artifact()` / `generate_post_local()` | 本地落盘时前置 `<站点id>/` |
| `publish_post_local()` / `publish_artifact()` | 从站点目录读取源；站点为空则跳过 |
| `collect_published_ids()` / `export_posts_concurrent($ids,$conc,$mode)` | 支持按站点筛选与分发 |
| `export_post()` / `export_post_by_switches()` | 读取 `cfse_site` meta 决定站点集合 |
| 编辑页 | 新增"站点"入口：点「设置」**弹出面板**（页面内模态/浮层，可自由摆放字段），不做下拉展开；另加"批量设置站点"入口 |
| `get_hosting_targets()` / `sanitize_hosting_targets()` | `id` 数字化、`dir` 推导、`is_default` |
| 设置页托管目标表 | 改为"摘要 + [设置] 展开面板"（互斥收拢）+ 端点列变宽 |

## 7. 已定事项（原开放问题，已有结论）

1. **编辑页站点控件形态**：点「设置」**弹出面板**（自由设置），不做下拉。
2. **改归属后旧目录残留**：**不自动清理**（当前走 Worker 端渲染，本地产物非必需；需要时手动删除目录即可）⇒ 避免误删风险。
3. **生成时目录自动创建**：**支持**（本地文件系统天然如此）。站点可填目录名（仅英文/数字），留空 = `id`；**选定离手**（保存后不可改）。
