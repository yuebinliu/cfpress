| **单页缓存头** | ⚙️ 基础配置 `:885` | 它只是写进单页 HTML 的 `<meta http-equiv="Cache-Control">` —— **CDN 不看 meta**；真正的响应头由 Worker 静态分支给（`routes.js:344`）。**本来就是个摆设** |

## 4. 「问号说明」的做法（本次定案的新交互）

**目的**：让右列 360px 放得下开关与按钮（说明不再占版面）。

| 说明长度 | 做法 |
|---|---|
| 一行内 | `<span class="dashicons dashicons-editor-help" title="……"></span>`（悬停即现）|
| 较长 / 含多条 | `<details><summary>说明</summary>……</details>`（点击展开）|

**项目现有先例**（照抄即可）：
- `dashicons-editor-help` + `title` —— 编辑页「对齐本篇」旁（`render_worker_sync_metabox()`）
- `<details>` —— 编辑页「存为 MD 格式」面板（`render_doc_format_metabox()`）

⚠️ 注意：`title` 里不要放 HTML；`<details>` 里的 form 控件**仍受外层 `<form>` 约束**（见 §5）。

## 5. 硬约束（违反会出问题）

| 约束 | 说明 |
|---|---|
| **option 键名一个都不改** | `cf_sync_d1` / `cf_gen_static` / `cf_publish_remote` / `cf_purge_sidebar` / `cf_purge_lists` / `cf_worker_auto_check` / `cf_comments_*` —— 名字与 value 都不动 ⇒ 零迁移 |
| ⚠️ **input 不能搬出 `<form action="options.php">`** | 设置页参数靠它提交；搬块前**先确认该 form 的起止范围**，把 input 搬到 form 外 ⇒ **设置静默丢失** |
| 按钮是**独立 form**（`admin-post.php?action=…`）| 可放任意位置 ✓ |
| 保留 `nonce` / `name` / `id` / `onchange` | 尤其 `cf_pub_remote` 的 `onchange`（勾 R2 ⇒ 自动勾 `#cf-gen-static`）|
| 保留 `.cfse-grid` 列定义 | `minmax(0,1fr) minmax(280px,360px)` + card `min-width:0`（AGENTS.md 批BS 的坑，别改回 `2fr 1fr`）|
| 主操作区放**右列** | ⇒ 需要 `.cfse-grid` 的**右列**容纳它；若 360px 仍挤，可放宽到 `minmax(320px,420px)`（左列相应变窄）|
